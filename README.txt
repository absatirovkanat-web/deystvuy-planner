ДЕЙСТВУЙ! — файлы для установки как PWA

Эта версия подготовлена для публикации на бесплатном HTTPS-хостинге.
Файлы сайта: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

После публикации по HTTPS:
1. Откройте адрес сайта в Chrome на Android.
2. Нажмите меню ⋮.
3. Выберите «Установить приложение» или «Добавить на главный экран».

Данные планера хранятся локально в браузере этого устройства.
Автоматической синхронизации между телефоном и ноутбуком нет.
Для переноса используйте экспорт/импорт в разделе «Итоги».
